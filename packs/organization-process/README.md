# Operations Knowledge Base

How an organization works: units, roles, processes, policies, systems and measures.

An Oto pack in the organization domain: the ontology `organization-process` (release 1) under `ontology/`, the skill `start` that begins a project from it, and the views under `views/`. Install it in Claude Code from the registry's marketplace, or `oto pack add organization-process` on a machine.

`oto pack check` validates it; `oto pack refresh` re-embeds the ontology when the registry holds a newer release; `oto pack publish --to <registry>` releases it.
