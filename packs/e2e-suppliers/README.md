# e2e-suppliers

Suppliers and who to reach at each: a throwaway pack for the end-to-end test of connected graphs.

An OTO pack in the procurement domain: the ontology `e2e-suppliers` (release 1) under `ontology/`, the skill `start` that begins a project from it, and the views under `views/`. Install it in Claude Code from the registry's marketplace, or `oto pack add e2e-suppliers` on a machine.

`oto pack check` validates it; `oto pack refresh` re-embeds the ontology when the registry holds a newer release; `oto pack publish --to <registry>` releases it.
