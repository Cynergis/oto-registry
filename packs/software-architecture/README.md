# Architecture Knowledge Base

Software estate: systems, components, interfaces, data, environments, decisions and risks.

An Oto pack in the software domain: the ontology `software-architecture` (release 5) under `ontology/`, the skill `start` that begins a project from it, and the views under `views/`. Install it in Claude Code from the registry's marketplace, or `oto pack add software-architecture` on a machine.

`oto pack check` validates it; `oto pack refresh` re-embeds the ontology when the registry holds a newer release; `oto pack publish --to <registry>` releases it.
